# Applied DCF Valuation Modeling

**Financial Modeling & Valuation | Practical Application**

## Project Overview
A practical application of the Discounted Cash Flow (DCF) valuation methodology using a structured financial modeling framework.

The project focuses on forecasting financial performance, estimating free cash flows, determining the weighted average cost of capital (WACC), and deriving an implied equity value.

## Model Preview



## Key Areas Covered
- Financial projections and operating assumptions
- Working capital and PP&E forecasting
- Weighted Average Cost of Capital (WACC)
- Unlevered Free Cash Flow (UFCF)
- Terminal value using Perpetuity Growth and Exit Multiple methods
- Sensitivity and scenario analysis
- Implied equity value and share price estimation

## Tools & Techniques
- Microsoft Excel
- Financial Modeling
- DCF Valuation
- Sensitivity Analysis

## Project Scope
The financial model was independently rebuilt from scratch using a separate Excel template, with the original case data retained as the basis for the analysis.

The project involved structuring the model, developing financial projections, implementing valuation calculations, and conducting sensitivity and scenario analysis to estimate the company's intrinsic value.
